Advanced Features

Note: This is a placeholder for upcoming features that are planned for implementation.

Local Web Server

A locally hosted web server will be implemented, allowing you to make POST requests to control various aspects of the application. Capabilities will include:

  • Retrieving compiler errors.
  • Checking compiling statuses.
  • The other AI can survey the progress and do post requests for the next prompt if there are errors.
  • It'll have access to the blueprint file and cant make changes to it.

Master AI Loop

You will be able to run a master AI from the server to create an automated, closed-loop system. The web server configuration file will be fully editable for advanced users who want to customize its behavior.
