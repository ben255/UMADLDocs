UMADL Blueprint

UMADL generates a blueprint file for your software. This file is structured in JSON format and is specifically designed for the AI to read, understand, and build upon.

Starting a New Project

When creating a new project, you must choose which folder will serve as your codebase folder. The blueprint file will be generated and stored inside this directory. Note: If you do not select a codebase folder, errors will be thrown when trying to proceed.

Continuing a Previous Project

If you are returning to a previously created project, you can choose a specific file to generate a blueprint of your existing code. This allows the AI to grasp the current state of your project so you can smoothly continue right where you left off.
